## What it is

Finding how far a number is from zero, which is its absolute value. The absolute value of -7 is 7.

## The one idea

Absolute value is a distance, and a distance is never negative. -7 and 7 are both seven steps from zero.

## Common stumbles

- Keeps the minus sign and says the absolute value of -7 is -7.
- Thinks absolute value means the opposite, and turns 7 into -7.
- Counts the zero mark as a step and says 8.

## Two concrete models

- A number line with jumps drawn from zero to the number.
- Walking: seven steps back is still seven steps.

## Worked example

What is the absolute value of -7? Start at zero and jump to -7. That is seven jumps. The absolute value is 7.

## Language to use

- how far from zero
- steps from zero
- a distance

## Language to avoid

- modulus
- magnitude of a vector
- the absolute value function
