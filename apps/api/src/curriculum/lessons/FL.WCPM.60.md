## What it is

Reading a decodable passage aloud smoothly enough to reach about sixty correct words a minute, with the words still understood.

## The one idea

Fluency is not speed for its own sake. Reading smoothly leaves room in your head to follow the story.

## Common stumbles

- Reads fast and loses accuracy, skipping or substituting words.
- Reads every word correctly but stops after each one, so the sentence never arrives.
- Repeats the start of a sentence several times before getting through it.

## Two concrete models

- Echo reading: the adult reads a sentence and the child reads the same sentence straight after.
- The same short passage read three times, so the third reading is smooth by familiarity rather than by rushing.

## Worked example

Read the passage once for accuracy. Read it again and try to make the sentences sound like talking. Read it a third time and notice how much easier it has become.

## Language to use

- smooth
- like you are talking
- read it again

## Language to avoid

- words correct per minute
- prosodic
- automaticity
