## What it is

Knowing that in a two-digit number the left digit counts tens and the right digit counts ones, and being able to say which digit sits in each place.

## The one idea

Where a digit sits decides what it counts: the same 4 means four tens in 47 and four ones in 74.

## Common stumbles

- Reads the other place, so asked for the tens of 47 the child says 7.
- Says what the digit is worth instead of the digit, so the tens of 47 becomes forty.
- Repeats the whole number when asked for one digit of it.

## Two concrete models

- Place-value blocks: build the number with tens rods and loose ones cubes, then count the rods for the tens and the cubes for the ones.
- A two-box place-value chart labelled tens and ones, with one digit written in each box.

## Worked example

Build 47 with four tens rods and seven ones cubes. Point at the rods and say four tens, so the tens digit is 4. Point at the cubes and say seven ones, so the ones digit is 7.

## Language to use

- tens place
- ones place
- digit
- how many tens

## Language to avoid

- positional notation
- base ten system
- numeral
