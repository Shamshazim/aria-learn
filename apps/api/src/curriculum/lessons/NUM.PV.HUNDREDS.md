## What it is

Knowing that in a three-digit number the digits count hundreds, tens and ones from left to right, and being able to say which digit sits in each place.

## The one idea

Each place is ten times the place to its right, so a digit moved one place left is worth ten times as much.

## Common stumbles

- Reads the place next door, giving the tens digit when asked for the hundreds.
- Says what the digit is worth, so the hundreds digit of 352 becomes three hundred.
- Repeats the whole number when asked for one digit of it.

## Two concrete models

- Place-value blocks: hundreds flats, tens rods and ones cubes laid out in three columns.
- A three-box place-value chart labelled hundreds, tens and ones, one digit in each box.

## Worked example

Build 352 with three flats, five rods and two cubes. The flats are the hundreds, so the hundreds digit is 3. The rods are the tens, so the tens digit is 5.

## Language to use

- hundreds place
- tens place
- digit
- how many hundreds

## Language to avoid

- positional notation
- magnitude
- numeral
