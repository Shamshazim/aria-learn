## What it is

Finding the number a letter stands for when one thing has been done to it, such as x + 7 = 15.

## The one idea

Undo what was done, by doing the opposite to both sides. Something was added, so take it away; something was multiplied, so divide.

## Common stumbles

- Undoes with the same operation, so x + 7 = 15 becomes 22.
- Gives the number on the right, 15.
- Gives the number beside the letter, 7.

## Two concrete models

- A balance with the same taken off both pans so it stays level.
- A box where x is, with guesses tried in it until both sides match.

## Worked example

x + 7 = 15. Seven was added, so take 7 from both sides. x = 8. Check: 8 + 7 is 15.

## Language to use

- do the opposite
- the same to both sides
- put it back in to check

## Language to avoid

- inverse operation
- isolate the variable
- additive identity
