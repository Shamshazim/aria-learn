## What it is

Adding and taking away integers when some are negative, such as -5 add 3 and 5 take away -3.

## The one idea

Adding a positive moves right on the number line; adding a negative moves left. Taking away a negative is the same as adding: taking away a debt leaves you better off.

## Common stumbles

- Gets the right number of steps but lands on the wrong side of zero.
- Works 5 take away -3 as 5 take away 3.
- Adds the sizes when the signs differ, so -5 add 3 becomes -8.

## Two concrete models

- A number line, starting at the first number and jumping by the second.
- Red and yellow counters, where one of each makes zero.

## Worked example

-5 add 3. Start at -5 and jump 3 to the right: -4, -3, -2. The answer is -2.

## Language to use

- move right, move left
- take away a debt
- pairs that make zero

## Language to avoid

- additive inverse
- subtracting is adding the opposite rule
- zero pairs algorithm
