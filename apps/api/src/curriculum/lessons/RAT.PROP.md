## What it is

Using a known price for some items to find the price for a different number: 3 pens cost $12, so how much do 5 cost?

## The one idea

Find what one costs, then build up. $12 for 3 pens is $4 each, so 5 pens cost five lots of $4.

## Common stumbles

- Adds a dollar for each extra pen and says $14.
- Repeats the $12 that was already given.
- Multiplies $12 by 5 and gets $60.

## Two concrete models

- A table with 1, 3 and 5 pens and their costs, filling in the row for one first.
- A double number line with pens on top and dollars underneath.

## Worked example

3 pens cost $12. One pen costs 12 shared by 3, which is $4. Five pens cost 5 times $4, which is $20.

## Language to use

- what does one cost
- each one
- build up from one

## Language to avoid

- cross-multiplication
- proportion equation
- constant of proportionality
