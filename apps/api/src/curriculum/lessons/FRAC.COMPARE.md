## What it is

Deciding which of two fractions with the same bottom number is larger.

## The one idea

When the pieces are the same size, more pieces is more. The bottom number tells you the size of a piece, not how much you have.

## Common stumbles

- Chooses the fraction with the bigger bottom number, saying one eighth is more than one third.
- Compares the top numbers without checking that the pieces are the same size.
- Says two fractions are equal because both have a one on top.

## Two concrete models

- Two fraction bars of the same length, cut the same way, stacked so the shaded lengths can be seen side by side.
- A number line from zero to one marked in the shared piece size, so both fractions land on it.

## Worked example

Compare five eighths and three eighths. Both bars are cut into eighths, so the pieces match. Five pieces is longer than three pieces, so five eighths is greater.

## Language to use

- same size pieces
- more pieces
- greater
- less

## Language to avoid

- common denominator
- cross-multiply
- order the rationals
