## What it is

Saying the number names one to twenty in order, and knowing that each name lands on one more thing than the name before it.

## The one idea

Counting is matching: one number name for one object, and the last name you say is how many there are.

## Common stumbles

- Says the names in order but points twice at one object, so the count runs ahead of the things.
- Reaches the end and cannot say how many, because the last word was a label rather than a total.
- Skips fifteen or says the teens out of order, most often eleven, twelve, thirteen.

## Two concrete models

- A number line from one to twenty: each step forward is one more, and the child walks the steps with a finger.
- A ten-frame filled one counter at a time: ten fills the frame, and the next counters start the second frame.

## Worked example

Count seven buttons. Touch each button once and say one, two, three, four, five, six, seven. Then ask how many, and answer seven, because seven was the last name said.

## Language to use

- how many
- one more
- the next number
- count on

## Language to avoid

- cardinality
- one-to-one correspondence
- enumerate
