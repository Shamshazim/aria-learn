## What it is

Deciding which of two decimals is bigger, such as 0.3 and 0.25, when they have different numbers of digits.

## The one idea

Length does not tell you size. Give both the same number of places, then compare: 0.3 is 0.30, and thirty hundredths is more than twenty-five.

## Common stumbles

- Thinks more digits means bigger, so 0.25 beats 0.3.
- Overcorrects and thinks fewer digits always means bigger, so 0.4 beats 0.75.
- Knows which is bigger but points the sign the wrong way.

## Two concrete models

- Two hundred-squares, one with thirty shaded and one with twenty-five.
- A number line from zero to one with both decimals marked on it.

## Worked example

Compare 0.3 and 0.25. Write 0.3 as 0.30. Thirty hundredths and twenty-five hundredths. Thirty is more, so 0.3 > 0.25.

## Language to use

- give them the same number of places
- tenths are bigger pieces
- which is closer to one

## Language to avoid

- annexing zeros
- lexicographic order
- the decimal expansion
