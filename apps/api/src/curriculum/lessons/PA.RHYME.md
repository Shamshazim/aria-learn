## What it is

Hearing that two words end with the same sound, with no letters involved.

## The one idea

Rhyme is about the ear, not the page. Words that rhyme finish the same way even when they are spelled differently.

## Common stumbles

- Matches on the first sound instead of the last, pairing cat with cup.
- Matches on meaning, pairing cat with dog because both are animals.
- Looks for the same spelling, so said and bed do not sound like a pair.

## Two concrete models

- Say the pair slowly and stretch the ending, so the shared part is the loudest thing in the room.
- A short chain: cat, hat, mat, sat, and let the child add the next one.

## Worked example

Cat and hat. Say both, hold the ending. Both finish with at, so they rhyme. Cat and cup both start with the same sound, but the endings are different, so they do not.

## Language to use

- sounds the same at the end
- say it slowly
- listen

## Language to avoid

- rime unit
- phonogram
- orthographic pattern
