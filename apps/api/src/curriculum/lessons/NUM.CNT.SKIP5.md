## What it is

Counting five, ten, fifteen, twenty and on, so that a group of five is counted as one jump instead of five separate steps.

## The one idea

Skip counting is counting groups. Every jump is five, so the numbers get big faster than counting by one.

## Common stumbles

- Falls back into counting by one after the first jump, so the sequence becomes five, six, seven.
- Adds one to the previous number instead of five, giving five, ten, eleven.
- Knows the chant but cannot say how many objects five jumps stands for.

## Two concrete models

- A number line marked only at the fives, so the empty space between marks is what one jump covers.
- Hands: each hand is five fingers, so counting hands is counting fives.

## Worked example

Count four hands of fingers. Say five, ten, fifteen, twenty. Four jumps of five is twenty fingers.

## Language to use

- jump by five
- a group of five
- how many groups

## Language to avoid

- multiples
- increment
- skip-count by an interval
