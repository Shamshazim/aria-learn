# Aria Learn

An AI tutor for children, TK through grade 8.

## Status

The project is being rebuilt from scratch. The first version is frozen under
[`legacy/`](legacy/LEGACY.md) and is no longer built or run.

## Target stack

| Part | Stack |
|---|---|
| Frontend | React + TypeScript + Vite |
| Backend | Node + Express + TypeScript |
| Database | PostgreSQL |
| Models | Hosted only. No local models. |
